PORTFOLIO BTS SIO
=================

Fichiers :
- index.html : page principale du portfolio
- style.css  : design responsive

UTILISATION
1. Ouvre index.html dans ton navigateur.
2. Remplace "Prénom Nom", "Nom de l'entreprise", les dates et les informations du stage.
3. Ajoute tes vrais projets et technologies.
4. Remplace l'adresse e-mail et les liens GitHub / LinkedIn.

Le portfolio est responsive et fonctionne sur ordinateur, tablette et téléphone.
